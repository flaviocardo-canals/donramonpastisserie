# AdminDW

Panel local para editar productos, precios, descripciones y disponibilidad.

1. Abrir `adminDW/index.html` desde Live Server.
2. Editar los campos necesarios.
3. Pulsar **Descargar products.json**.
4. Reemplazar `products.json` en la raíz del repositorio.
5. Hacer commit y push desde VS Code.

La versión actual no tiene autenticación ni base de datos. Los cambios guardados en el navegador solo sirven como borrador local hasta exportar el JSON y subirlo al repositorio.
